# Future Vision

Esta pasta contém explorações visuais de funcionalidades ainda não contratadas.

Regras:

- os artefatos daqui não são mocks canônicos;
- não podem originar requisitos, APIs, schemas ou regras de produto;
- não são promovidos para `mockups/` enquanto as funcionalidades correspondentes permanecerem deferidas;
- toda função ilustrada deve apontar para uma entrada em `_bmad-output/planning-artifacts/deferred-features.md`;
- `DESIGN.md` e `EXPERIENCE.md` vencem em qualquer conflito;
- o HTML deve identificar visualmente a exploração como **visão futura — não implementável no escopo atual**.
